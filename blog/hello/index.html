I was left with no choice but to try to either reconstruct it or start anew. I chose the latter.


The original site was written in Hugo. I enjoyed my time with it, but got tired of how indirect it was.


This new site is completely raw HTML and CSS. We'll see if I like it this way, or how long I last doing it like this. Welcome back, or welcome for the first time. I swear there will be content of substance again eventually.
